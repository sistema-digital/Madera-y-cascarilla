1. Sube TODOS los archivos conservando esta misma estructura.
2. La PWA debe abrirse mediante HTTPS (o localhost durante pruebas).
3. No funciona como PWA si abres index.html directamente con file://.
4. Android/Chrome puede mostrar el botón "Instalar app".
5. En iPhone/iPad: Safari > Compartir > Añadir a pantalla de inicio.
6. Supabase requiere conexión a Internet; la interfaz y recursos estáticos quedan cacheados.
